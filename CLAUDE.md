## Working in this repository

- Read the files you're changing before editing them, and match the surrounding style.
- Keep changes focused on the request; don't reformat or rewrite unrelated code.
- Before finishing: `pnpm typecheck`, `pnpm lint` and `pnpm format:check`, plus a browser check for UI changes.
- Never print, commit or rewrite `.env`; append new keys to both `.env` and `.env.example`.
- Never push without being asked.
