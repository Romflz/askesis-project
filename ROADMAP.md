# Roadmap

What's planned for Askesis next. Nothing here has a date yet, and the order may change. Ideas and feedback are welcome
in the issues.

## Planned

### Images on cards

- Add pictures to the front or back of a card: upload a file or paste from the clipboard.
- Images show in study sessions, the practice drill and the card browser, and scale to fit phones.
- Imports and exports keep them, so a deck with images survives a backup.

### Notes

A notes page next to your decks, for everything that doesn't fit on a card.

- Write in Markdown (`.md`), with headings, lists, tasks, tables, code blocks and LaTeX math.
- Tag notes with `#tags`, nest them like `#chemistry/organic`, and browse or filter by tag.
- Organize notes in folders, link them to each other with `[[note name]]`, and see which notes link back.
- Search across every note.
- Import and export plain `.md` files, so your notes stay yours and open in any Markdown editor.

### Shop

- Spend the coins you earn from daily chests, quests and lucky finds.
- `/shop` is a placeholder for now, and every coin earned until it opens stays in your balance.

### Career roadmaps

A roadmap page for each career, such as Linux administrator, frontend developer, DevOps engineer or data analyst,
showing what to learn and in which order.

- Each roadmap is a path of steps from the basics to advanced topics, with the practice decks for each step: for a
  Linux administrator, the filesystem decks from basics to advanced, then the command line and Bash scripting.
- Start any step in one click. Signed in, your progress shows on the path and finished steps are checked off.
- Roadmaps are public pages, like the practice decks, so anyone can follow one without an account.

### Health stats

- See how your studying is going over time: workload, backlog, lapses, session length and missed days.
- Get a nudge when something slips, such as a growing backlog or too many new cards at once, with a suggestion for
  getting back on track.
